# OpenTherm Boiler Emulator

**Status:** Planned

## Overview

This project aims to develop an OpenTherm boiler emulator for testing and development of heating control systems.

The emulator will simulate the behavior of an OpenTherm-compatible boiler, allowing communication with heating controllers without requiring a physical boiler.

## Project Goals

- Understand and implement the OpenTherm communication protocol.
- Develop hardware for interfacing with OpenTherm controllers.
- Implement firmware to simulate boiler responses.
- Test and validate communication between the emulator and external controllers.

## Technologies

- Embedded C/C++
- Microcontrollers
- OpenTherm protocol
- Electronics and PCB design

## Progress

The project is currently in the planning stage. Hardware design, firmware implementation, and testing will be documented here as development progresses.
